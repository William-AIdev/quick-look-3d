Scope: baseline/CI, Meshopt, Draco, lifecycle/resource cleanup and demand rendering. Binary transfer, thumbnails, caches and asset UI are deferred.

## Changes

- PR01: exact direct dependency pins and lockfile, typecheck before bundling, fail on missing prerequisites, one renderer build per scripted app build, macOS CI.
- PR02/03: Meshopt and Draco work together; decoder JS/WASM are embedded. Runtime guards the WASM data URL and build checks a single HTML file without external scripts/styles. Licenses ship inside the extension. Three.js 0.171.0 is pinned; its private Draco loader hook needs regression testing on upgrades.
- PR04: reused page and pageReady handshake, async scoped file reads, request UUIDs, stale-result rejection, first-frame/error completion, cancellation and 60-second timeout. Weak script handler avoids retention. Blob URLs, stale roots, mixers, skeletons, model and page resources are disposed. WebContent termination retries once, then fails the pending request.
- PR05: coalesced RAF invalidation for static scenes; VRM/animation updates continue while visible. Native and document visibility suspend scheduling and reset elapsed time on resume. Controls damping and resize invalidate rendering. Pixel ratio remains capped at 2. New model loading draws one initial frame for native completion even if hidden; continuous hidden rendering is suspended.

## Reproduce

    bash scripts/build.sh
    node renderer/generate-fixtures.mjs
    bash scripts/test-native.sh
    npm --prefix renderer audit --audit-level=high

Optionally set QL_TEST_FBX and QL_TEST_VRM to absolute local paths before running test-native.sh. Assets are read only and never copied into fixtures. Synthetic triangle/animation fixtures are generated by the committed script and can be redistributed. CI needs no private models.

App: build/Build/Products/Release/QuickLook3D.app (local ad-hoc signature). Installation, notarization and release distribution are separate from development acceptance.

## Unverified boundaries

- Finder/Quick Look host behavior of this new build, actual WebContent process termination, and the previously observed system warning. Recent logs did not recover the warning; do not attribute it to a legacy qlgenerator without reproduction, timestamp and bundle evidence.
- Real VRMA, empty geometry, textured Tripo compression combinations and broad asset compatibility. Animated glTF and FBX/VRM do not establish all VRMA behavior.
- Before/after model-loading baselines, independent cold processes, RSS/GPU memory peaks, CPU/battery percentages, 100 native host preview cycles and multi-version macOS coverage. Geometry counters are not process-memory measurements.

Review findings resolved: unbounded termination retries capped and tested; Meshopt license included; embedded-WASM assumption guarded; idle-test zero-frame false positive prevented. No known implementation defect remained open in local review.
