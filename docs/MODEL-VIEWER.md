# 模型文件查看器：行为与验收

本次将主程序改成模型文件查看器。Quick Look 空格预览保留为附加入口，Finder 图标缩略图由独立 QLThumbnailProvider 扩展处理。

## 使用方式

- 拖入或选择文件夹，递归索引 GLB、VRM、VRMA、FBX；忽略隐藏文件、包和符号链接。超过 100 个相关文件先确认，拒绝不会提交列表或准备数据缓存。
- 文件夹、文件列表和只读安全作用域书签持久保存。启动恢复列表，不重新解析整个目录；刷新更新文件签名。系统“打开方式”打开单个模型时，仅导入该文件并进入三维查看。
- 单击选择文件，双击或按“打开三维”进入交互查看；返回列表释放三维模型。列表使用静态缩略图，避免同时运行大量三维视图。支持目录筛选、收藏筛选、搜索、排序和取消批量任务。
- 字段可以选择：实测绘制 FPS、顶点、三角形、材质数、纹理尺寸、每段动画时长。静止状态显示空闲，未知信息显示未知。FPS 与配置的动画绘制上限不同。顶点/三角形统计按场景中的网格实例计数，材质和纹理按实际资源去重。
- 系统打开文件事件、库文件刷新和三维载入均校验源文件。源文件变化、离线或书签失效时，刷新或重新导入。

## 缓存与资源取舍

导入只扫描文件属性，不读取每个模型的完整载荷。可见缩略图按需生成，也可以显式批量生成；超过 100 项的批量任务先确认。缩略图服务同时最多提交两项请求，原生后备渲染器串行工作，并定期回收 WebView。

软件的 PNG/元数据缓存与 macOS 的 Finder 缩略图缓存独立。软件优先通过公开 QLThumbnailGenerator API 请求系统缩略图；系统不能提供时，软件内部使用自己的渲染器。软件缓存按文件设备/inode、大小和纳秒修改时间失效。Finder 缓存由系统管理，不能保证永久存在，也不作为软件唯一数据库。

预览数据缓存预算可选 1–256 GiB，浏览缩略图/信息预算 256 MiB–8 GiB。收藏会准备数据缓存，并保护相关数据和浏览缓存不被自动淘汰；收藏总量可以超过软预算。可分别清理非收藏或全部软件缓存，均不删除源文件。缓存实现仍使用前一版本的协调读写、载荷校验与 LRU；共享目录与签名限制见前次文档。

FBX 继续使用现有 Three.js FBXLoader：数据缓存保存原 FBX，不能跳过解析、纹理解码或 GPU 上传。节能纹理优化仍只对支持的 GLB/VRM 生效。FBX 内嵌图片临时 Blob URL 在纹理加载后撤销；替换、取消和返回列表都会走模型清理流程。默认节能/30 FPS，关闭动画和静止时停止绘制；降低绘制上限不会消除模型常驻资源。

## 本机真实素材测量

环境：Apple Silicon、macOS 27.2、本地 ad-hoc Release/回归程序。只读素材目录含 114 个 FBX，总计约 3.71 GiB。下表为单次顺序生成 256×256 缩略图的记录，不是多轮统计或所有 Finder 场景的保证。

| 项目 | 实测 |
| --- | ---: |
| 文件成功数 | 114/114 |
| 缩略图中位延迟 | 388.5 ms |
| 缩略图 P95 延迟 | 1301.0 ms |
| 浏览缓存 PNG 与元数据 | 6,326,478 字节，约 6.03 MiB |
| 整次测量耗时，含编译/测试准备 | 70.50 s |
| 主进程 RSS 峰值 | 224.16 MiB |
| WebContent 候选进程 RSS 峰值 | 1085.30 MiB |
| GPU 候选进程 RSS 峰值 | 609.05 MiB |
| Networking 候选进程 RSS 峰值 | 159.41 MiB |

每 0.2 秒用 ps 采样。主进程按测试程序标识，WebKit 仅按启动前后新增 PID 归类；不是 coalition 归属证明，也不是 physical footprint 或独占 GPU 内存。各项峰值不一定同时出现，不应简单相加。WebContent 峰值样本只有一个候选进程；最终样本 WebContent 为零，主进程约 141.6 MiB。大 FBX 的解析仍可产生较高短时峰值，文件读取上限不是 RSS 上限。

早期测试中顶层自动释放池延迟释放视图，造成多个 WebContent 进程累计约 8.5 GiB；该结果不作为交付性能。已修正渲染入口与弱引用检查的释放边界，并保留每次替换后旧控制器释放的断言。完整 114 项复测通过。

## 验证记录

可复现脚本：


test-viewer.sh 验证真实 LibraryModel、100/101 确认边界、取消、列表与书签重启、收藏、缓存失效与保护、可见缩略图像素、元数据、单文件打开。设置 QL_TEST_FBX_FOLDER 与 QL_TEST_ALL_FBX=1 可复测全部实际目录。measure-viewer.py 记录该批次 RSS；原始文件名与完整样本仅保存在本地 build 目录，不提交用户素材。

test-native.sh 验证缓存/扫描器、离线 Draco/Meshopt、真实 FBX/VRM/官方 VRMA、实测 FPS 与暂停、100 次替换、回调一次性与控制器释放。test-shared.sh 验证不同沙盒签名身份共享设置和缓存。process-recovery.py 验证实际 WebContent 进程退出与恢复。test-system-thumbnails.py 用可清理的独立测试应用走公开系统缩略图 API，并检查图像确有内容，避免只检查 API 成功。

本机公开系统 API 已验证 GLB、VRM、真实 FBX 缩略图，均包含可见内容且没有载入遮罩；不依赖导入库，也不依赖修改默认打开程序。开发中修改扩展支持类型后，本机缩略图服务曾缓存旧提供者选择；刷新服务后成功。真实 Finder 的图标显示仍由系统设置、缓存和提供者选择决定。详见 viewer-validation.json；远端 CI 状态见交付链接。仍未声称已验证实际 Finder 图标刷新、物理拖拽、发布签名/公证、App Store 配置、CPU/功耗或原始系统警告归因。不会覆盖 /Applications 中的现有 QuickLook3D.app。
